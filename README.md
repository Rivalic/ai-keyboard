# AI Keyboard

An AI-powered keyboard extension for iOS with intelligent text predictions.

## 🚀 Quick Start

This project uses GitHub Actions to build the iOS app automatically - no Mac required!

### Build IPA File

1. Fork or clone this repository
2. Push to GitHub
3. GitHub Actions will automatically build the IPA
4. Download from Actions → Artifacts

See [GITHUB_ACTIONS_GUIDE.md](GITHUB_ACTIONS_GUIDE.md) for detailed instructions.

## 📱 Features

- 🤖 AI-powered text predictions
- ✨ Smart autocomplete
- 📝 Grammar checking
- 🎨 Beautiful modern UI

## 🔧 Installation

### Option 1: GitHub Actions (Recommended)
1. Push code to GitHub
2. Download IPA from Actions artifacts
3. Install via AltStore

### Option 2: Build with Xcode (Requires Mac)
1. Open `AIKeyboard.xcodeproj`
2. Build and run

## 📥 Installing IPA on iPhone

Use **AltStore** (Windows/Mac):
1. Download AltStore: https://altstore.io
2. Install AltStore on iPhone
3. Sideload the IPA file
4. Enable keyboard in Settings

See [INSTALL_WITHOUT_MAC.md](INSTALL_WITHOUT_MAC.md) for details.

## 🛠️ Requirements

- iOS 15.0+
- For building: GitHub account (free)
- For installation: AltStore or Apple Developer account
